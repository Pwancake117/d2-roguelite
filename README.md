# D2 Roguelite

A roguelite run tracker for Destiny 2. Start each run on a fixed base build with common gear, earn loot and abilities from activities you clear, and lose it all when you run out of lives.

**Play:** https://pwancake117.github.io/d2-roguelite/

## What it does
- Base build for every class and subclass (including Prismatic), with unlocks for supers, grenades, melees, class abilities, aspects and fragments.
- Loot drops scaled by activity tier and difficulty; deaths cost a life and a looted item.
- Connect your Bungie.net account to equip your run loadout in game (gear and subclass), and to log finished activities automatically.
- DIM links and search strings for players who prefer DIM.
- Export runs as CSV or JSON.

Bungie.net sign-in is handled by Bungie; this app only stores your run data in your own browser.
